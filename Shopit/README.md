# Shopit

A frontend-only React e-commerce demo.

## Stack
- React + Vite
- React Router
- Tailwind CSS
- DummyJSON Products API
- localStorage for demo authentication and cart persistence

## Features
- Home page
- Product catalog with API data
- Search, category filtering and sorting
- Product details
- Cart
- Frontend-only Login / Signup
- Simple demo checkout

## Run locally

```bash
npm install
npm run dev
```

Authentication and checkout are intentionally frontend-only and are not production-secure.
